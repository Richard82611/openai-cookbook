# Suno Lyrics Assistant (Chinese)

A lightweight Python utility that generates:

1. A Chinese songwriting instruction set.
2. A structured user prompt template for lyric generation.
3. A focused Suno-style prompt block for composition and production guidance.

## Quickstart

```bash
python examples/suno_lyrics_assistant/lyrics_prompt_assistant.py
```

## Test

```bash
python -m pytest examples/suno_lyrics_assistant/tests
```
